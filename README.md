# Lab 4 - Flutter Widgets

Mobile Programming, Laboratory Work 4.

The app has a home screen with a list of all tasks. Tap a task to open it.

1. Checkbox & Switch
2. TextFormField login form
3. FloatingActionButton counter
4. CircularProgressIndicator & SnackBar
5. AlertDialog & bottom sheet
6. Slider & date picker
7. ListView.builder with Dismissible
8. GridView gallery
9. BottomNavigationBar & TabBar
10. Card & ExpansionTile

## Run

```
flutter pub get
flutter run
```
